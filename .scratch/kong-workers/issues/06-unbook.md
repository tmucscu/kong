# 06: `/unbook`

**What to build:** A Member can delete one of their own future Bookings through a select. Admins see every future Booking. The deletion is announced publicly, and an Admin deleting someone else's Booking says so.

**Blocked by:** 03

**Status:** ready-for-agent

- [x] With nothing to delete, a clear message is shown
- [x] Public announcement names who deleted which Booking, noting when an Admin removed someone else's
- [x] A Member cannot delete another Member's Booking by replaying a request
