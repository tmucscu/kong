# Kong

Kong is the CSCU Discord server's in-house bot. It runs only in the CSCU server.

## Language

**Member**:
Anyone in the CSCU Discord server. Kong keeps no separate list of members.
_Avoid_: Roster, user list

**Office**:
The one shared CSCU room that members can book. There is exactly one.
_Avoid_: Room, space

**Booking**:
A claim on the Office for a span of time on a single day, made by one person.
_Avoid_: Reservation, slot

**Taco**:
A public shoutout one Member gives another, always with a reason.
_Avoid_: Point, kudos

**Season**:
The span of time a Taco leaderboard covers. An Admin ends the current Season and starts a new one; tacos from past Seasons are kept and can still be viewed.
_Avoid_: Reset, wipe, term

**Admin**:
A Member with the Manage Server permission in the CSCU server. Admins can delete any Booking, remove any Taco, and start a new Season.
_Avoid_: System Admin, Developer

**Display name**:
A person's current nickname in the CSCU server. Kong only shows it and never uses it to identify anyone; people are identified by their Discord user ID.
_Avoid_: Name (as an identifier)
